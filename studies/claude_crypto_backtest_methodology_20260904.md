# 코인계좌 손절원칙 백테스트 방법론 (study20_crypto)

작성일: 2026-09-04 · 스크립트: `study20_crypto_stop_backtest.py`, `crypto_lib.py`

## 1. 목적

BTC/ETH/TRX 세 종목에 서로 다른 손절 방식(A/B/C)을 적용했을 때, 종목간 2차(전량)손절거리(%)가 얼마나 균일한지를 비교한다. 표준편차가 낮을수록 "같은 원칙이 종목 특성과 무관하게 균일하게 작동한다"는 뜻이다.

## 2. 데이터

| 종목 | 소스 | 확보 구간 | 비고 |
|---|---|---|---|
| BTC | Alpha Vantage `DIGITAL_CURRENCY_DAILY` | 2010-07-17 ~ 2026-09-03 | 정상 수신 |
| ETH | Alpha Vantage `DIGITAL_CURRENCY_DAILY` | 2015-08-08 ~ 2026-09-03 | 정상 수신 |
| TRX | Binance 공식 히스토리(`data.binance.vision`, `TRXUSDT-1d` 월별 klines) | 2026-01-01 ~ 2026-07-31 | AV가 TRX 미지원(확인됨) → 대체 |

**표본 구간 절단**: TRX가 7월까지만 확보되어, 세 종목의 "최신일" 기준을 통일하기 위해 BTC/ETH도 2026-07-31로 절단한 후 재계산했다. 이 절단이 없으면 종목별 경과 거래일수가 달라져(BTC/ETH는 진입 후 ~62거래일, TRX는 ~20거래일) 표준편차 비교 자체가 왜곡된다.

**1시간봉 미사용 사유**: Alpha Vantage 무료 키에서 `CRYPTO_INTRADAY`가 프리미엄 전용으로 막혀 있음을 재시도로 재확인(같은 실패가 파라미터를 바꿔도 동일하게 발생). 사용자 승인 하에 일봉으로 진행.

## 3. 진입/체결 규칙 (전 후보 공통)

- 진입가: 데이터소스의 그날 종가가 아니라 **계좌 실제 체결가**를 사용 (BTC 62,146.63 / ETH 1,744.25 / TRX 0.3027, 진입일 2026-07-03)
- 1차(50% 매도): 종가가 stop1 아래로 마감 확정 → **익일 시가**에 체결
- 2차(전량 매도): 당일 저가가 stop2를 터치 → **그 가격(stop2)** 으로 즉시 체결
- 같은 날 1차 대기 중 2차 조건이 먼저 충족되면 **2차 우선** (1차 대기 무효, 사이클 즉시 종료)
- 단일 사이클, 재진입 없음

## 4. 후보 정의

**A · 눌림목(피벗, 기존 방식)**
피벗저점(order=3, 확정 3거래일후) 가격을 stop1/stop2로 사용. 래칫(하락 무시, 상향만 반영).

**B · ATR 배수**
ATR(20일) × 배수(mult1). 그리드 mult1 ∈ {3, 4, ..., 15} (사용자 확정 범위). stop2 배수 = mult1 × 1.5 (기존 stop1/stop2 = x2/x3 비율 유지). 8/31 장비주 전환 시 적용한 것과 동일한 ATR 관습(20일 period).

**C · 하이브리드 클램프**
A 또는 B(최적 배수)를 베이스로, 당일 종가 대비 손절거리(%)를 **8%~20%** 범위로 강제 클램프(사용자 확정, 문서 예시값)한 후 래칫(상향만) 재적용. `clamp(dist_pct, 0.08, 0.20)` → `new_stop = close × (1 - clamped)` → `cur = max(cur, new_stop)`.

## 5. 핵심 결과 (2026-07-31 기준)

| 후보 | 종목간 2차손절거리 표준편차(%p) |
|---|---|
| A 눌림목 | 2.83 |
| B ATR(최적배수 x3) | 3.41 |
| **C-on-A** | **0.85 (최소)** |
| C-on-B | 2.21 |

세 종목 모두 표본 구간(진입 후 28거래일) 동안 1차·2차 어느 쪽도 발동하지 않아, 실제 손절 발동 시나리오는 이번 표본에서 검증되지 않았다.

## 6. 알려진 한계 (재현 시 반드시 확인)

1. **표본 구간이 28거래일로 짧다.** TRX 8~9월 데이터를 추가로 확보하면 BTC/ETH도 원래 보유 구간(9/3까지)으로 되돌려 재계산해야 한다.
2. **B 후보 최적배수(x3)가 테스트 그리드의 최하단 경계값.** x3 미만(x1~x2)을 테스트하지 않았으므로 그 구간에 더 낮은 표준편차가 존재할 가능성을 배제할 수 없다.
3. **TRX의 데이터소스-실제체결가 괴리(6.84%)가 BTC(0.60%)·ETH(0.68%)보다 크다.** TRX는 계좌와 동일 거래소(Binance) 데이터를 썼음에도 괴리가 더 크다 — 저유동성 종목의 일중 변동폭 또는 체결 슬리피지 가능성이 있으나 이 데이터만으로 원인을 단정할 근거는 없다.
4. TRX 데이터는 Binance 공식 klines(마이크로초 타임스탬프, UTC), BTC/ETH는 Alpha Vantage 집계 데이터로 **소스 자체가 다르다** — 두 소스의 가격 산정 방식(거래소 커버리지 등)이 다를 수 있음에 유의.

### 9-2. 결정적 신규 발견 — 평시(2026-07-03~07-31) 조기발동 점검

이 구간은 5종목 모두 B&H 기준 −6~+8% 내외로 뚜렷한 급락이 없었다. 그런데도:

- **B(ATR, 최적배수 x1)는 5종목 전원이 이 구간 안에 2차(전량청산)까지 발동**했다(BTC 7/24, ETH 7/28, TRX 7/27, XRP 7/24, BNB 7/24).
- A(눌림목)는 5종목 중 1종목만 완전청산(BNB 7/17), 1종목은 1차만(XRP 7/14) — 상대적으로 안정.
- C-on-A, C-on-B는 클램프의 8% 하한이 노이즈를 걸러내 5종목 모두 미발동.

즉 그리드를 x1까지 넓혀도 "통계적으로 가장 균일한" 배수가 실전에서는 노이즈만으로 전 종목을 청산시키는 결함이 있음이 이번에 처음 확인됐다. study20은 표본 구간에 트리거가 전혀 없어 이 결함이 드러나지 않았다.

## 10. 최종 판정 (채택 가능 / 보류 / 기각)

- **A 눌림목 — 보류(4개 중 가장 유력)**: 급락 방어력 최상 + 평시 안정성 양호. 단 균일성(원래 문제의식)은 4개 중 최악, 미해결.
- **B ATR(x1) — 기각**: 평시 5/5 전량청산이라는 결정적 결함 확인. 통계적 균일성과 실전 사용성이 상충.
- **C-on-A — 보류**: 균일성 최소 + 평시 안정성 최상. 단 A 단독보다 급락 방어력이 약함 — 트레이드오프 존재.
- **C-on-B — 기각**: 평시엔 안정적이나 급락 시 B&H와 다름없어 손절 시스템으로서 의미 없음.

**애매함을 그대로 보고**: "균일성"과 "실제 방어력"이 서로 다른 후보를 가리키는 데다, 최선 후보(A, C-on-A) 사이의 우열도 이번 표본만으로는 가리기 어렵다. 단일 후보를 자신있게 확정할 근거는 아직 부족하다.

## 11. 알려진 한계 (재현 시 반드시 확인)

1. TRX/BNB 데이터가 2026-07-31까지만 확보되어, FAIR 비교는 전 종목이 이 날짜로 절단됨. INDIVIDUAL(BTC/ETH/XRP 9월초까지)과는 표본 길이가 달라 직접 비교 불가.
2. B 그리드를 x1까지 넓혔음에도 최적값이 다시 새 하한에 걸림 — 다만 x1 자체가 9-2에서 확인된 결함으로 사실상 기각되어, 그리드를 더 낮추는 방향은 의미가 없다고 판단.
3. 급락구간 시뮬레이션의 진입가는 계좌 실제 체결가가 아니라 그 시점(2026-05-15) 데이터소스 종가 — 순수 "트리거 발동 시 성과" 검증 목적의 가상 진입점.
4. XRP/BNB는 미보유 종목이라 가상 진입가 방식 자체가 실전과 다를 수 있음(슬리피지·체결지연 미반영).

# study24 — 다구간 교차검증 (study23 후속, 2026-09-04)

스크립트: `study24_crypto_multi_period.py`

## 13. study23 대비 변경점

1. **"종목간 손절거리 균일성" 지표 완전 제거** — study23에서 잘못된 목표였음을 확인, 이번엔 산출하지 않음.
2. **후보를 A(눌림목)·C-on-A(클램프) 2개로 축소** — B(ATR), C-on-B는 study23에서 명확히 기각되어 참고용으로만 병행 산출.
3. **3개 구간 교차검증**: 2026-01-14~02-20(급락), 2026-05-15~07-10(급락, study23 재사용), 2026-08-01~데이터 최대치(급등).
4. **진입가 규칙**: 모든 구간·모든 종목의 진입가 = 그 구간 시작일 데이터소스 종가로 통일(계좌 실제 체결가 미사용) — "구간 시작=독립된 신규 진입"이라는 방법론과 일관되게 하기 위한 판단. study23의 급락구간 시뮬레이션과 동일한 방식.
5. **놓친 수익(missed upside) 지표 신설**: 청산 이후 그 구간 데이터 끝까지의 최고종가 대비 청산가 대비 상승폭 — 조기발동 비용을 정량화.

## 14. 핵심 결과 — 3구간 B&H 대비 개선폭(%p)

급락 2회 모두 A가 C-on-A보다 방어력이 컸다(순위 뒤집힘 없음). 급등구간에서는 C-on-A가 3종목 전원 미발동으로 B&H를 오차 없이 재현한 반면, A는 XRP 1종목에서 1차(50%)가 발동해 소폭 손해를 봤다. 3구간 모두 우열이 일관되게 나타났고, 특정 구간에서만 순위가 뒤집히는 현상은 없었다.

## 15. 최종 판정

- **A(눌림목) — 채택 가능성 높음**: 3구간 중 2구간(급락)에서 더 우수, 1구간(급등)에서만 근소하게 열위. 누적으로 C-on-A보다 유리.
- **C-on-A(클램프) — 채택 가능성 있음(근접 2위)**: 급등구간 무손실이 뚜렷한 강점. 급락 방어력은 A보다 항상 약간 약함.
- **B(ATR)/C-on-B — 기각 유지**: 이번 3구간에서도 MDD 최악(급락) 또는 전량청산(급등, 3/3) 패턴이 재확인됨. 근본 원인(평시 조기청산 결함)이 study23에서 이미 규명되어 재검증하지 않음.

## 16. 알려진 한계

1. 표본이 여전히 작다(구간당 3~5종목, 구간 3개) — 통계적 유의성보다는 방향성 확인 수준.
2. BNB는 1~2월/8~9월 구간에서 데이터 부재로 제외, TRX는 8~9월 구간에서 제외 — 완전한 5종목 x 3구간 매트릭스는 아님.
3. 진입가를 구간 시작일 종가로 통일한 것은 "독립 사이클" 방법론과의 일관성을 위한 판단이며, 브리핑 문서의 원안(실제 체결가 우선)과는 다르다는 점을 명시함.
4. "놓친 수익" 지표는 사후적 지표(그 시점엔 알 수 없었던 정보)이므로 실시간 의사결정 근거로 오인하지 않도록 주의.

## 18. study25 — 2단계 분할(A-2tier) vs 단일화(A-1tier)

**배경/가설**: 코인은 실적발표 등 펀더멘털 반등 촉매가 없어 추세전환 후 미끄러지듯 하락하는 경향이 있다면,
1차(50%)에서 추세전환이 확정된 후에도 나머지 50%를 2차까지 들고가는 현행 2단계 분할이 오히려 손해일 수
있다는 사용자 가설을 검증(반대가설: 2단계가 노이즈필터 역할을 해 성급한 전량청산을 막는 순기능도 가능).

**후보**: A-2tier(기존, study23/24의 A와 동일 — 1차 50%/2차 전량) vs A-1tier(신규 — 최신 확정 피벗 1개
라인만 써서 하회 확정 시 분할 없이 100% 즉시 매도). 두 후보가 동일한 stop1 라인을 공유하도록 설계해
"분할 여부" 자체만 격리 비교.

**대상/구간**: study24와 동일한 3구간·5종목·데이터갭 예외 그대로 재사용. TRX 8월 데이터는 이번에도
재확인했으나(data.binance.vision 목록이 JS 렌더링이라 확인 불가) 미확보 확정 — study24와 동일하게 제외.

**핵심 결과**:

| 구간 | 성격 | A-2tier 평균수익률 | A-1tier 평균수익률 | 차이(2t−1t) | 평균 미끄러짐(발동후) | 잔여50% 기여도 |
|---|---|---|---|---|---|---|
| 2026-01~02 | 급락 | -13.03% | **-11.87%** | -1.16%p | -6.56% | +1.80%p |
| 2026-05~06 | 급락 | -7.89% | **-6.91%** | -0.98%p | -4.36% | +1.87%p |
| 2026-08~09 | 급등 | **+27.97%** | +26.40% | +1.57%p | -0.84%(n=1) | -3.69%p |
| **누적** | | | | **-0.57%p(1tier가 근소 우위)** | | |

- **가설 검증(추세전환 후 미끄러짐)**: 급락 2구간 모두 1차 발동 후 그 사이클 최저가가 fill1 대비 평균
  -6.56%/-4.36% 더 하락했다 — "중간반등 없이 미끄러진다"는 가설을 뒷받침하는 직접 증거.
- **A-2tier 잔여 50% 손실분**: 급락 2구간 모두 양수(+1.80%p, +1.87%p) — 분할 때문에 못 턴 나머지 50%가
  실제로 추가 손실을 발생시켰음을 확인.
- **반대가설(2단계=노이즈필터) 검증**: 급등구간에서는 잔여 50% 기여도가 음수(-3.69%p) — 즉 그 구간에서는
  나머지 50%를 들고 간 것이 오히려 이득이었다(XRP 1종목만 발동, 2차엔 도달 못한 채 데이터 종료). A-1tier의
  놓친 상승분(missed upside)은 +7.42%로 3구간 중 가장 컸다.
- **순효과**: 급락 2구간의 1-tier 우위(각 -1.16%p, -0.98%p)와 급등구간의 2-tier 우위(+1.57%p)가 거의
  상쇄되어, 3구간 누적 차이는 -0.57%p(1-tier가 근소 우위)에 불과하다 — 구간 성격에 따라 방향이 뒤집히는
  결과이며, 어느 한쪽이 압도적으로 우수하다고 보기는 어렵다.

**최종 판정**: 애매하다(양쪽 다 근거가 있음, 그대로 보고). 급락 방어력만 보면 1-tier가 근소하게 낫고
(미끄러짐/잔여손실 지표가 사용자 가설을 직접 지지), 급등구간 수익보존만 보면 2-tier가 근소하게 낫다.
3구간 누적으로는 거의 무승부(-0.57%p)라 통계적으로 "명확히 우수하다"고 단정할 근거는 부족하다.

**알려진 한계**:
1. 표본이 작다(구간당 3~5종목, 구간 3개, 급등구간 트리거 이벤트는 XRP 1건뿐).
2. BNB(5~6월 구간)에서 1차 없이 2차가 직행 발동한 사례가 1건 있었다(당일 저가가 2차선까지 직행 터치) —
   이 경우 A-2tier와 A-1tier의 "분할 여부" 격리 비교 전제가 성립하지 않아 슬리피지/잔여손실 지표 계산에서
   제외(None) 처리했다.
3. 잔여 50% 손실분·미끄러짐 지표는 2차가 실제 도달하지 못한 경우 구간 마지막 종가로 근사했다(실제 2차가
   아님에 유의, 해당 건은 note 필드로 표시).
4. 진입가 규칙은 study24와 동일(구간 시작일 종가 통일, 계좌 실제 체결가 미사용).
